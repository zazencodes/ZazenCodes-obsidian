# Aerospace cheat sheet

Config file: `~/.aerospace.toml`

(running the default config)

```bash
# switch workspaces
alt + 1–9
alt + a–z

# send window to workspace
alt + shift + 1–9
alt + shift + a–z

# quickly toggle between last two workspaces
alt + tab

# resize current window (smart resize)
# shrink
alt + -
# expand
alt + =

# move focus between windows
alt + h    # left
alt + j    # down
alt + k    # up
alt + l    # right

# move window in tile tree
alt + shift + h    # move left
alt + shift + j    # move down
alt + shift + k    # move up
alt + shift + l    # move right

# join two windows into same container (stack/group)
alt + shift + ;
alt + shift + h    # join with left
alt + shift + j    # join with down
alt + shift + k    # join with up
alt + shift + l    # join with right

# service mode (will see [s] appear by aerospace upper-right icon when active)
alt + shift + ;

# toggle floating / tiling layout (workspace-wide)
# (use when windows are overlapping or behaving unexpectedly)
alt + shift + ;
f

# make current window fill entire tiled area
# (easier option is just send it to another workspace)
# (this command will close all other windows)
# (only works in tiling mode)
alt + shift + ;
backspace
```
